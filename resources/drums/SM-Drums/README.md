# SM Drums (condensed)

Free deeply sampled acoustic drum kit by Scott McLean, Tod Stillwell and
Suleiman Ali ("SM Drums", SFZ version: https://github.com/sfzinstruments/SMDrums).

This folder holds a condensed version for Ton of Able, made with
`tools/drums/convert_smdrums.py`: stereo room mix, 8-16 evenly spaced velocity
layers and 3-4 round robins per drum, decays trimmed below -70 dBFS, 16-bit FLAC.
The hand clap comes from the AVL Drumkits (../AVL-Drumkits).

Lanes: 36 kick, 37 sidestick, 38 snare (6.5"), 39 clap, 42 / 44 / 46 hi-hat
closed / pedal / open (choke group), 45 / 47 / 50 toms low / mid / high,
49 crash 16", 51 ride 20".
